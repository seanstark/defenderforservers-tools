ARCHITECTURE & TECHNICAL REFERENCE

Solution documentation, queries, APIs & permissions

How the Azure Function worker discovers Azure Arc servers, correlates Defender for Endpoint (MDE) telemetry, and manages Entra ID group membership.

Architecture

Generated and validated with Archify (showcase quality profile · 9/9 layout & route checks passed). Click any component node below to inspect its upstream/downstream connections and role in the synchronization pipeline.

Interactive node inspector: Select any component node in the Archify diagram above to highlight its connected data flows and view its implementation details.

Scoped Discovery & Queueing

  • Inventory (NCRONTAB timer) and ArcEvent (Event Grid write) validate Management Group, Subscription, and Resource Group scope.
  • Azure Resource Graph discovers Microsoft.HybridCompute/machines and resolves management group subscriptions.
  • Service Bus queue decouples discovery spikes from per-machine correlation with 10-delivery dead-letter protection.

Hunting-Only MDE & Safe Group Sync

  • All MDE telemetry (DeviceInfo, DeviceNetworkInfo, scid-2010 AV mode, tags, MachineGroup) comes via Graph /security/runHuntingQuery.
  • Requires Connected Arc machine, unique unmerged Onboarded MDE record within FreshnessHours, and enabled Entra device.
  • Audit mode records WouldAdd; Enforce mode writes mutation intent first, adds directory object ID, and verifies read-back.

Isolated Read-Only Reporting

  • Atomic Azure Table batch commits current state and h_ history snapshots plus system/inventory and log_ execution logs.
  • Separate Report Function App has only Storage Table Data Reader and enforces Entra Easy Auth + Report.Reader role.
  • Interactive Defender-style portal provides KPI filters, hover popovers, context drawer, Function App telemetry, and docs.
Workflow

The solution runs two isolated PowerShell 7.4 Azure Function Apps on a dedicated App Service plan: a privileged worker app (Managed Identity only) and this read-only report app (protected by Microsoft Entra Easy Auth and the Report.Reader app role).

  1. Discovery triggers: Runs on a scheduled timer (default every 30 minutes via Inventory) and in near-real-time via Event Grid (Microsoft.HybridCompute/machines/write routed to ArcEvent), queueing work onto the machines Azure Service Bus queue.
  2. Arc validation: Reads the Azure Arc resource in ARM and requires properties.status == "Connected" and in-scope Management Group, Subscription, and Resource Group.
  3. MDE correlation: Queries the latest DeviceInfo record per DeviceId over 7 days and matches AzureResourceId to the full Arc resource ID. Ignores merged devices (MergedToDeviceId), requires OnboardingStatus == "Onboarded", and enforces evidence freshness (default 24h, configurable 1–168h).
  4. Entra resolution: Requires a valid GUID in AadDeviceId, resolves the directory object via GET /devices?$filter=deviceId eq '...', requires accountEnabled == true, and uses the directory object id (never deviceId or Arc Managed Identity) for group operations.
  5. Add-only group safety: Verifies the target group is a cloud-managed, assigned, non-role-assignable security group. In Audit mode, reports WouldAdd. In Enforce mode, writes a durable mutation intent before POST /groups/{id}/members/$ref and verifies direct membership read-back. Never deletes devices or removes group members.
Queries used (Azure Resource Graph & Defender XDR Advanced Hunting)

Azure Resource Graph — Arc machine discovery

Executed against configured Subscriptions and/or Management Groups (with optional Resource Group filter):

Resources
| where type =~ 'microsoft.hybridcompute/machines'
| where tolower(resourceGroup) in ("<optional-rg-filter>")
| project id
| order by id asc

Azure Resource Graph — Management group subscription resolution

Resolves member subscriptions when SYNC_MANAGEMENT_GROUP_IDS is configured (cached 15 minutes):

ResourceContainers
| where type =~ 'microsoft.resources/subscriptions'
| project subscriptionId

Defender Advanced Hunting — MDE device correlation & tags

Selects latest state per DeviceId before matching AzureResourceId (POST /v1.0/security/runHuntingQuery):

DeviceInfo
| where Timestamp >= ago(7d)
| summarize arg_max(Timestamp, *) by DeviceId
| where AzureResourceId =~ "<arc-resource-id>"
| project Timestamp, DeviceId, DeviceName, AadDeviceId, OnboardingStatus, MergedToDeviceId,
    SensorHealthState, CloudPlatforms, AzureVmId, PublicIP,
    DeviceManualTags, DeviceDynamicTags, RegistryDeviceTag, MachineGroup
| take 101

Defender Advanced Hunting — Network adapter IP addresses

Collects latest IPv4/IPv6 addresses per adapter for the correlated MDE DeviceId:

DeviceNetworkInfo
| where Timestamp >= ago(7d) and DeviceId == "<mde-device-id>"
| summarize arg_max(Timestamp, *) by DeviceId, NetworkAdapterName, MacAddress
| project IPAddresses
| take 101

Defender Advanced Hunting — Antivirus mode (scid-2010)

Extracts AV mode from TVM configuration assessment (0=Active, 1=Passive, 2=Disabled, 3=Other, 4=EDRBlocked, 5=PassiveAudit):

DeviceTvmSecureConfigurationAssessment
| where Timestamp >= ago(7d) and DeviceId == "<mde-device-id>" and ConfigurationId == 'scid-2010'
| summarize arg_max(Timestamp, *) by DeviceId
| project DeviceId, Timestamp, AvMode = tostring(parse_json(Context)[0][0])
| take 2

Scope combination rules (Management Groups, Subscriptions & Resource Groups)

When multiple scope settings are configured simultaneously, the worker evaluates scope using OR (union) between Management Groups and Subscriptions, and AND (intersection filter) for Resource Groups:

InScope = (Subscription in SYNC_SUBSCRIPTION_IDS OR Subscription in SYNC_MANAGEMENT_GROUP_IDS)
          AND (SYNC_RESOURCE_GROUP_NAMES is empty OR ResourceGroup in SYNC_RESOURCE_GROUP_NAMES)
SYNC_MANAGEMENT_GROUP_IDS SYNC_SUBSCRIPTION_IDS SYNC_RESOURCE_GROUP_NAMES Resulting Scope
Set (mg-prod) Empty Empty All Arc machines in any subscription under mg-prod.
Empty Set (sub-1) Set (rg-arc) Only Arc machines in rg-arc within sub-1.
Set (mg-prod) Empty Set (rg-arc) Only Arc machines in a resource group named rg-arc across any subscription under mg-prod.
Set (mg-prod) Set (sub-extra) Set (rg-arc) Only Arc machines in rg-arc inside either sub-extra or any subscription under mg-prod (deduplicated per inventory pass).
