ONE-STEP REMEDIATION SCRIPTS

Grant or update Managed Identity permissions

Run these PowerShell / Azure CLI commands from the entragroup-sync directory to assign any missing Azure RBAC or Microsoft Graph permissions.

1. Assign Azure Reader Role (Required for Resource Graph)

Required on every target Subscription or Management Group so Azure Resource Graph can discover Arc machines, VMs, and VMSS instances:

# Assign Reader on target Subscription or Management Group
az role assignment create --assignee-object-id <worker-principal-id> --assignee-principal-type ServicePrincipal --role 'Reader' --scope '/subscriptions/<subscription-guid>'

2. Grant Microsoft Graph & Administrative Unit Permissions

Grants ThreatHunting.Read.All and Device.Read.All plus AU-scoped Groups Administrator on your Administrative Unit (no tenant-wide GroupMember.Read.All required):

# Administrative Unit scoped (checks & manages only groups in the Administrative Unit)
.\Grant-GraphPermissions.ps1 -WorkerPrincipalId '<worker-principal-id>' -Mode Enforce -AdminUnitId '<admin-unit-guid>'
Background processing uses a separate managed identity. Times are shown in your local timezone.
